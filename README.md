# Toca Certo

Primeira versão da página do **Toca Certo**, um serviço de diagnóstico e recomendação personalizada para quem quer montar o primeiro sistema de vinil ou planejar o próximo upgrade.

> Você não precisa do toca-discos mais caro. Precisa do sistema certo para o seu espaço, orçamento e forma de ouvir música.

## O que está incluído

- VTSD inicial do serviço;
- apresentação das jornadas “Meu Primeiro Setup” e “Meu Próximo Upgrade”;
- proposta beta e exemplo demonstrativo do relatório;
- questionário interativo de diagnóstico;
- navegação responsiva para computador e celular;
- cartão de compartilhamento do Toca Certo.

## Rotas

- `/` — página de apresentação e venda;
- `/questionario` — protótipo do questionário pós-compra.

## Estado do projeto

Esta é uma versão beta usada para validar a proposta, a oferta e o processo de diagnóstico. O checkout ainda não está conectado e os primeiros projetos-piloto ainda serão realizados.

Não existem depoimentos fictícios, números inventados de clientes ou promessas de desempenho de equipamentos.

## Executar localmente

Requisitos: Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Para conferir a versão de produção:

```bash
npm run build
```

## Tecnologias

- React;
- TypeScript;
- Next.js;
- CSS responsivo.

## Marca

**Toca Certo** é o nome provisório do projeto. A Vivinil não é a marca responsável pelo serviço; poderá aparecer futuramente apenas em benefícios complementares relacionados a oportunidades de discos.
